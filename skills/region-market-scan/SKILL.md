# 지역 관광시장 스캔

한 지역에서 관광 관련 사업을 할 만한지 판단하는 리포트를 만든다.

## 언제 이 스킬을 쓰나

| 질문 | 스킬 |
|---|---|
| "여기 오는 사람은 누구인가" (성·연령·거주지·체류) | `region-visitor-profile` |
| **"여기서 사업할 만한가" (수요 대비 공급)** | **이 스킬** |
| "특정 숫자 하나만 알고 싶다" | `datalab-query` |

## 두 가지 쓰임

| 상황 | 명령 |
|---|---|
| 한 곳을 깊게 본다 | `scan.py` |
| 후보지 여러 곳을 나란히 놓는다 | `compare.py` |

## 한 곳 깊게 보기 — scan.py

```bash
python3 {SKILLS_DIR}/region-market-scan/scripts/scan.py \
  --region 강릉시 --from 202401 --to 202412 --out /tmp/scan.html
```

| 옵션 | 설명 |
|---|---|
| `--region` | 시군구 이름 또는 5자리 코드. 여러 곳에 걸리면 후보를 보여 주고 멈춘다 |
| `--from` `--to` | `YYYYMM`. 최대 18개월 |
| `--out` | HTML 저장 경로 |
| `--no-compare` | 유사지역 비교를 건너뛴다(호출 수가 줄지만 판단 기준이 사라진다) |

리포트는 Artifact로 발행할 수 있는 HTML이다(문서 래퍼 없음).

## 리포트가 답하는 것

### 요약 — 여섯 숫자

| 지표 | 계산식 |
|---|---|
| 성수기 배수 | 최대월 방문자 ÷ 최소월 방문자 |
| 숙박 비율 | 데이터랩의 월별 숙박 비율을 순방문자 수로 가중평균 |
| **객실당 월 숙박 방문자** | 월평균 숙박 방문자 ÷ 객실 수 |
| 관광사업체 순증 | 기간 내 개업 − 폐업 |
| **시도 안 방문자수 순위** | 시도 안 시군구를 방문자 수로 세운 자리 |
| **시도 안 지출액 순위** | 시도 안 시군구를 카드 지출액으로 세운 자리 |
| **관광수요 지수** | 데이터랩 종합 지수. 같은 기간 전국값과 나란히 |

객실당 월 숙박 방문자는 같은 방식으로 계산한 **유사지역 평균과 나란히**
놓인다. 이 값이 유사지역보다 크면 숙박 공급이 상대적으로 빠듯하다는 신호다.

### 시도 안에서 이 지역은 어디쯤인가

다른 지표가 "이 지역이 얼마나"를 말한다면, 순위 두 줄은 "**옆 동네보다
나은가**"에 답한다. 출점 자리를 고를 때 절대값보다 이쪽이 먼저 필요할
때가 많다.

```
시도 안 방문자수 순위   2위 / 18곳   35,220,438명 · 시도 안 비중 12.3%
시도 안 지출액 순위     1위 / 18곳   864,165,011천원 · 시도 안 비중 15.9%
```

알아야 할 것 셋.

- **시도 안에서의 자리다.** 다른 시도와 견줄 수 없다 — 시도마다 시군구
  수가 다르다(서울 25곳, 강원 18곳).
- **현지인을 뺀 값이다.** 다만 두 지표의 구분 체계가 다르다 —
  방문자는 외지인 + 외국인이고, **지출액은 외지인만**이다(소비 지표에는
  외국인 구분 자체가 없다). 전체를 쓰면 현지인이 섞여 대도시가 부풀려
  보이는데, 그건 관광시장이 아니라 유동인구다.
- **지출액은 내국인 카드 소비다**(외국인이 아니다). 데이터랩의 같은
  화면에 카드사가 다른 갈래가 여럿 있고 값이 95배까지 차이 난다.
  어느 쪽이 어느 카드사인지는 확정하지 못했으므로, "관광 지출액 1위"
  라고만 옮겨 말하지 말고 내국인 카드 기준임을 밝혀라.
- **지출액 단위가 천원이다.** 다른 섹션의 원 단위 값과 나란히 놓지 마라.

두 지표(`BDT_01_01_002` · `BDT_02_01_002_33`)는 SGG_CD라는 이름으로
**시도 두 자리**를 받는다. 수집 계층이 알아서 바꿔 보내지만,
`datalab-query`로 직접 부를 때는 `--sido`를 써야 한다.

### 전국에서의 관광 경쟁력

시도 안 순위가 "**옆 동네보다 나은가**"라면, 이 표는 "**전국에서 어디쯤
인가**"에 답한다. 데이터랩이 방문·소비·검색·SNS를 묶어 만든 종합 지수를
네 축으로 나누고, 전국 252개 시군구 안에서의 자리를 준다.

```
축              값     전국평균  평균 대비  순위          백분위
관광 수요 강도   73.8   71.4      103%      62위 / 252곳   상위 25%
관광자원수요     70.8   70.8      100%      80위 / 252곳   상위 32%
관광 이동거리    72.1   75.5       95%     126위 / 252곳   상위 50%
관광 다양성      64.5   74.6       86%     200위 / 252곳   하위 21%
```

정선군은 수요 강도는 전국 상위 25%인데 다양성은 하위 21%다. **두 자리가
크게 어긋나는 지역이 있다** — 시도 안에서 앞자리인데 전국에서는 중간인
경우다. 그래서 두 표를 함께 싣는다.

알아야 할 것 셋.

- **값의 단위가 공개돼 있지 않다.** 절대값을 인용하지 말고 전국 평균
  대비와 순위로 읽어라.
- **모집단이 축에 따라 바뀐다.** 시군구로 부르면 252곳, 시도로 부르면
  17곳이다. "3위"만 떼어 말하면 어느 쪽인지 알 수 없다.
- **데이터랩은 순위와 그것을 뒤집은 값을 나란히 준다.** 뒤집은 쪽을
  순위로 읽으면 1등이 꼴등이 된다. 이 리포트는 두 값의 관계를 확인한
  뒤에만 표를 내고, 어긋나면 표 대신 경고를 낸다.

네 축은 관광 자원 수요 · 관광 수요 강도 · 관광 다양성 · 관광 이동거리
이고, 그 아래 8중분류 59세부지표가 있다. 세부까지 보려면:

```bash
A={SKILLS_DIR}/datalab-fetch/scripts/activate.py
python3 $A axes    51770 --from 202401 --to 202412
python3 $A groups  51770 --from 202401 --to 202412
python3 $A details 51770 --from 202401 --to 202412 --top 5
```

**옛 지수(`LN_09_*`)를 쓰지 마라.** 같은 화면의 이전 지표인데 2024년
5월에 멈췄고 값 체계도 다르다(2024-01 강남구가 옛 지수 100.0, 지금
지수 128.08). 색인에는 남아 있으니 `datalab-query`로 부를 수는 있지만
섞으면 안 된다. 그중 `LN_09_01_002`는 특히 위험하다 — `SGG_CD`를
받으면서 무시하고 전국 값만 준다.

### 네 섹션

- **수요** — 방문자 수, 숙박 방문자 수, 순방문자·숙박 비율(월별)
- **매력** — 인기관광지·지역맛집 Top100(검색량), 유료관광지점 입장객, 내비게이션 검색 유형,
  **현지인과 외지인이 각각 무엇을 찾는지**(강릉은 음식이 현지인 43.9% 대
  외지인 40.4%, 자연관광이 13.3% 대 17.6%다 — 그 차이가 곧 자리다)
- **공급** — 관광사업체 수·업종별 분포, 숙박 객실 수, 숙박시설 수, 개·폐업,
  **캠핑장 수·캠핑사이트 수·사이트 유형별 분포**
- **동네** — **읍면동별 방문자 수와 관광소비액**

#### 동네를 마지막에 두는 이유

앞 세 섹션이 시군구 전체를 보여 준 뒤라야 "그 안에서 어디"가 뜻을
갖는다. 순서를 바꾸면 읍면동 값을 시군구 값으로 읽기 쉽다.

**읍면동을 다 더해도 시군구가 되지 않는다.** 동 사이를 오간 사람이
동마다 한 번씩 세어지기 때문이다(강릉시 2024년 외지인 기준 1.99배).
통합시 산하 구를 더하면 안 되는 것과 같은 이유다.

두 표의 모집단도 다르다. 방문자는 **외지인만**이고(현지인이 빠져
있다), 소비는 카드 소비 전체다. "동네별 1인당 소비"를 내려고 나누면
분모가 좁아 부풀려진다.

#### 캠핑이 숙박과 따로 있는 이유

야영장업은 관광진흥법상 숙박업이 **아니다.** 그래서 `BZM_03_*` 숙박
지표에 캠핑장은 한 곳도 들어 있지 않다. 숙박 객실 수만 보고 "공급이
빠듯하다"고 판단하면, 캠핑 수요가 큰 지역에서는 실제 공급을 통째로
빼놓고 세는 셈이 된다.

**캠핑장 수와 캠핑사이트 수는 다른 지표다.** 강릉시 2024-12 기준
캠핑장 35곳에 사이트 2,366개 — 자릿수가 두 자리 다르다. 나누면
캠핑장당 평균 사이트 수가 된다(67.6개).

사이트 유형(일반야영장·자동차야영장·카라반·글램핑)은 사이트 시설
구분이고, 업종(일반야영장업·자동차야영장업)은 사업자 등록 구분이다.
**둘은 다른 분류라 섞으면 비중 합이 200%가 된다.**

## 여러 곳 비교하기 — compare.py

```bash
python3 {SKILLS_DIR}/region-market-scan/scripts/compare.py \
  --region 강릉시 --region 속초시 --region 양양군 \
  --from 202401 --to 202412 --out /tmp/compare.html
```

지역 2~8곳을 같은 잣대로 한 표에 놓는다. 열은 월평균 방문자, 성수기 배수,
숙박 비율, 객실 수, 객실당 월 숙박 방문자, 관광사업체 수, 사업체 순증
일곱 개다.

| 옵션 | 설명 |
|---|---|
| `--region` | 두 번 이상 넣는다. 같은 곳을 두 번 넣으면 거부한다 |
| `--sort` | 정렬 기준 열. 기본값은 `객실당 월 숙박 방문자` |
| `--asc` | 오름차순 |

**이 표는 어느 값이 좋다고 말하지 않는다.** 객실당 수요가 높으면 공급이
빠듯하다는 뜻인데, 그것이 기회인지 위험인지는 사업 모델이 정한다.
리포트에 "값이 크면 무엇을 뜻하는가" 용어표가 함께 실리니, 사용자에게
답할 때 그 문장을 근거로 삼고 순위를 좋고 나쁨으로 옮기지 마라.

동해안 4곳 2024년 실제 결과: 강릉 39.0 · 고성 38.4 · 양양 28.5 · 속초 23.3
(객실당 월 숙박 방문자). 속초는 객실 16,188실로 가장 많고 객실당 수요는
가장 낮다.

## 반드시 함께 읽어야 하는 것

리포트가 스스로 적어 두지만, 사용자에게 설명할 때도 빠뜨리지 마라.

### 객실당 수요는 가동률이 아니다

분자(숙박 방문자)는 **이동통신 기반 추정치**이고 분모(객실 수)는 **등록
기준 시점 재고**다. 성격이 다른 두 값의 비이므로 객실 가동률로 읽으면
안 된다. 같은 방식으로 계산한 다른 지역과 견줄 때만 뜻이 있다.

### 검색량은 방문이 아니다

인기관광지·지역맛집의 `검색건수`는 **내비게이션 목적지 검색 건수**다.
검색 없이 찾아가는 곳(주민 단골집, 도보 이동)은 잡히지 않는다.
"강릉에서 가장 많이 방문한 식당"이라고 옮겨 말하지 마라.

### 실측은 하나뿐이다

**유료관광지점 입장객 수만 매표 집계(실측)** 이고, 나머지 방문자 수치는
모두 추정이다. 리포트가 `[실측]` 표시를 단다.

### 저량과 유량

관광사업체·객실 수는 **특정 시점의 재고**, 방문자 수는 **기간 합계**다.
리포트 머리말의 "재고 기준 YYYYMM"이 그 시점이다.

### 내국인 소비는 시군구 단위로만 없다

데이터랩이 **시군구 단위** 내국인 카드소비 지표를 내렸다(2026-08 확인,
8개 qid 모두 HTTP 200에 0바이트). 이 리포트가 시군구 단위이므로 내국인
소비 항목이 없는 것은 누락이 아니라 데이터랩의 상태다.

**시도 단위는 다르다.** 야간관광 지표 `BY_TH_NIGHT_TOUR_002_002`의
`CNSM_AMT`가 시도별 월별 관광소비 총액을 현지인·외지인·외국인으로 나눠
준다(원 단위). 시도 수준으로 내국인 소비를 봐도 되는 질문이라면
`datalab-query`로 조회하라.

## 종료 코드

| 코드 | 뜻 | 할 일 |
|---|---|---|
| 0 | 정상 | — |
| 1 | 기간 형식·범위 오류 | `YYYYMM`인지, 18개월 이내인지 확인 |
| 2 | 지역 해석 실패 | 후보가 출력되면 하나를 골라 다시 실행 |
| 3 | 세션 만료로 아무것도 못 가져옴 | `datalab-auth` 스킬로 넘긴다 |
| 4 | 세션은 멀쩡한데 지표가 0개 | 지역코드·기간 확인 |

지표 일부만 실패하면 리포트는 정상 생성되고, 무엇이 왜 빠졌는지가
"데이터 수록 현황" 섹션에 남는다.

## 지켜야 할 것

- **세션을 자동으로 재생성하려 하지 마라.** 로그인은 사용자만 할 수 있다.
- 컬럼 라벨을 지어내지 마라. 사이트가 쓰는 이름을 그대로 쓴다.
- 소비 금액 단위는 컬럼마다 다르다(원·천원·백만원). 카탈로그의 `unit`을 따른다.

## 기간 쓰는 법

`--period` 로 사람 말을 그대로 쓸 수 있다. `--from`/`--to` 와 함께 쓸 수는 없다.

| 쓰는 말 | 풀리는 기간 |
|---|---|
| `--period 작년` | 지난 달력 연도 전체 |
| `--period 올해` | 올해 1월부터 지난달까지 (지표가 더 짧으면 그 지표까지) |
| `--period 최근12개월` | 지난달부터 거꾸로 12개월 |
| `--period 2024` | 2024-01 ~ 2024-12 |
| `--period 2024상반기` / `2024Q3` | 반기 · 분기 |
| `--period 202401-202412` | 직접 지정 |

**지표마다 데이터가 나와 있는 마지막 달이 다르다.** 아직 발표되지 않은
달을 물으면 데이터랩은 오류가 아니라 빈 배열을 준다. 확인:

```bash
python3 {SKILLS_DIR}/datalab-fetch/scripts/period.py show 사업체
python3 {SKILLS_DIR}/datalab-fetch/scripts/period.py latest LN_04_01_022
```
