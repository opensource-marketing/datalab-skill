# 인바운드 타겟 국가 브리핑

한국관광 데이터랩 데이터로 방한 타겟 국가를 5축 평가한다.
데이터 인출은 `datalab-fetch` Skill이 담당한다.

## 5축

| 축 | 의미 | 데이터 |
|---|---|---|
| 규모 volume | 기간 내 방한객수 | `NAT_08_01_021` |
| 성장 momentum | 전년 대비 증감률 | `NAT_08_01_021` |
| 지출력 value | 1인 평균지출과 1일 평균지출의 합성 | `NAT_07_01_018` (세션 필요, 연 단위 조사) |
| 접근성 access | 공급 좌석수 | `NAT_10_01_001` |
| 전환여지 headroom | 재방문율·재방문의향·추천의향 평균 | `NAT_07_01_018` (세션 필요, 연 단위 조사) |

각 축은 0~100으로 정규화된다.

**중요**: 정규화는 **그 축을 보유한 국가끼리만** 이뤄진다.
지출력 50점은 209개국 중 중위가 아니라 조사 대상 19개국 중 중위다.
반면 규모 50점은 209개국 중 중위다.
따라서 보유 국가수가 크게 다른 축의 점수를 서로 비교하지 마라.
축별 보유 국가수는 리포트의 축 커버리지 표에 있다.

## 세 가지 총점

리포트는 총점을 **세 가지**로 계산해 나란히 보여준다.

- **총점_보정** — **대표 지표다. 순위와 헤드라인은 이것을 쓴다.**
  아래 `총점`에 커버리지 수축 보정을 적용한 값이다.
- **총점** — 순위(백분위) 기반 원점수. "누가 1등인가"에 답한다. 보정 전 값이므로 감사용이다.
- **총점_값기반** — 상하위 5%를 winsorize한 뒤 값의 크기를 반영한 점수.
  "1등이 얼마나 압도적인가"에 답한다.
- **순위변동** — 값기반 순위에서 순위기반 순위를 뺀 값. 두 방식의 순위가
  크게 엇갈리는 국가일수록 리포트에서 흥미로운 신호다.

## 커버리지 수축 보정 — 반드시 이해하고 답하라

209개국 중 190개국이 5축 중 2~3개만 보유한다.
결측 축의 가중치를 재분배하면 총점은 0~100에 갇히지만,
**축이 적은 국가가 구조적으로 유리해진다.**
2개 축 국가는 두 가지만 잘하면 되고, 5개 축 국가는 다섯 가지를 다 잘해야 하기 때문이다.

보정 없이는 이스라엘(2축)이 1위, 미국(5축, 세 축에서 94점 이상)이 9위로 나왔다.
사업 조언으로는 틀린 결과다. 그래서 다음을 적용한다.

```
보유비율   = 사용된 축들의 원래 가중치 합 / 전체 가중치 합
총점_보정  = 50 + (총점 - 50) × 보유비율
```

축을 모두 보유한 국가는 보정이 없다. 가중치의 40%만 보유한 국가는
평균에서 벗어난 정도가 60% 줄어든다. 순위에서 배제하지는 않는다.

**사용자에게 순위를 말할 때는 `총점_보정` 기준으로 말하라.**
`총점`(원점수) 순위를 그대로 전달하면 위에서 폐기한 편향된 순위를 되살리는 것이다.

사용자가 업종을 말하지 않으면 어느 업종인지 물어라. 임의로 고르지 마라.

## 리포트 생성

```bash
python3 {SKILLS_DIR}/inbound-country-brief/scripts/brief.py \
  --profile 면세점 --period 작년 \
  --out /tmp/inbound-brief.html
```

종료 코드: `0` 성공 · `2` 인자 오류(형식/범위/알 수 없는 프로필) ·
`3` 세션 만료 · `4` 데이터 인출 실패. 0이 아니면 stderr 메시지를 그대로
사용자에게 전달하라 — 특히 3은 `datalab-auth` Skill로 안내하는 문구를 담고 있다.

생성된 HTML을 Artifact 도구로 발행해 사용자에게 링크를 전달한다.
발행 전 `artifact-design` 스킬을 읽어라.

## Q&A 모드

"일본 2분기 방한 추이 어때?" 같은 단일 질문에는 리포트를 만들지 말고
필요한 qid만 조회해 답하라.

```python
import sys
sys.path.insert(0, "{SKILLS_DIR}/datalab-fetch/scripts")
import workspace
from normalize import fetch_qid, to_frame

rows = fetch_qid("NAT_08_01_021",
                 {"natCd": "999", "BASE_YM1": "202504", "BASE_YM2": "202506"},
                 cache_dir=str(workspace.cache_dir()),
                 session_file=str(workspace.session_file()))
df = to_frame("NAT_08_01_021", rows)
print(df[df["국가명"] == "일본"])
```

## 결과를 해석할 때 지켜야 할 것

- **결측 축을 0점으로 말하지 마라.** 데이터가 없는 축은 가중치가 재분배된 것이지
  점수가 낮은 것이 아니다. 순위를 언급할 때는 반드시 `사용축수`도 함께 말하라.
- **사용축수가 다른 국가끼리 `순위변동`을 비교하지 마라.** 축이 적은 국가는
  정규화 방식 변경에 더 민감해서, 큰 순위변동이 실질 신호가 아니라 좁은
  축 집합의 변동성일 수 있다.
- **지출력·전환여지는 연 단위 외래관광객조사 데이터다.** 리포트에 찍힌
  실제 조사 연도(`조사연도`)를 함께 밝혀라. 2025년 조사와 2019년 조사는
  같은 지출력 수치라도 의미가 다르므로, 여러 연도가 섞여 있으면
  범위(예: `2019~2025`)로 그대로 전달하라.
- **세션이 만료되면 지출력·전환여지 두 축이 통째로 빠진다.** 일부 국가만
  채워진 반쪽 데이터로 점수를 매기면 왜곡되므로, 코드가 의도적으로
  두 축 전체를 비운다. 리포트에 세션 만료 경고가 보이면 이 사실을
  사용자에게 반드시 알리고, `datalab-auth` Skill로 안내하라. 직접
  로그인하려 하지 마라.

`--profile` 은 한글로 써도 된다: `면세점`·`호텔`·`여행사`·`마이스`·`중립`.
쓸 수 있는 말은 `profiles.yaml` 의 `aliases` 가 정한다.

## 기간 쓰는 법

`--period` 로 사람 말을 그대로 쓸 수 있다. `--from`/`--to` 와 함께 쓸 수는 없다.

| 쓰는 말 | 풀리는 기간 |
|---|---|
| `--period 작년` | 지난 달력 연도 전체 |
| `--period 올해` | 올해 1월부터 지난달까지 (지표가 더 짧으면 그 지표까지) |
| `--period 최근12개월` | 지난달부터 거꾸로 12개월 |
| `--period 2024` | 2024-01 ~ 2024-12 |
| `--period 2024상반기` / `2024Q3` | 반기 · 분기 |
| `--period 202401-202412` | 직접 지정 |

**지표마다 데이터가 나와 있는 마지막 달이 다르다.** 아직 발표되지 않은
달을 물으면 데이터랩은 오류가 아니라 빈 배열을 준다. 확인:

```bash
python3 {SKILLS_DIR}/datalab-fetch/scripts/period.py show 사업체
python3 {SKILLS_DIR}/datalab-fetch/scripts/period.py latest LN_04_01_022
```
