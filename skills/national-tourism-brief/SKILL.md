전에 이 값을 자신의 설치 경로로 바꿔라.

# 전국 관광 현황 브리프

다른 스킬은 모두 **어디**(시군구·시도)나 **누구**(국가)나 **무엇**(테마)을
축으로 본다. 이 스킬은 축이 없다 — **전국 전체**가 지금 어떤가에 답한다.

데이터랩 첫 화면이 그 층이다. 이 저장소는 화면 마흔 곳을 훑는 동안 정작
첫 화면을 한 번도 보지 않았고, 그래서 전국 요약 지표 스물다섯이 통째로
빠져 있었다.

## 쓰는 법

```bash
python3 {SKILLS_DIR}/national-tourism-brief/scripts/national_brief.py \
  --out /tmp/national.html
```

| 인자 | 뜻 | 기본 |
|---|---|---|
| `--from` / `--to` | 추이를 볼 기간 | 지난달에서 12개월 |
| `--age` | 인기 관광지를 볼 연령대(20·30·40·50·60) | 전 연령 |
| `--out` | HTML 경로 | 표준출력 |

`--from`과 `--to`는 **함께 주거나 함께 비워야 한다.** 한쪽만 주면 나머지를
우리가 지어내야 하는데, 사용자가 의도한 창인지 알 수 없으므로 거부한다.

숫자 하나만 필요하면 리포트를 만들지 말고 기반 계층을 직접 부른다.

```bash
python3 {SKILLS_DIR}/datalab-fetch/scripts/national.py summary
python3 {SKILLS_DIR}/datalab-fetch/scripts/national.py trend 방한외래객 \
  --from 202508 --to 202607
python3 {SKILLS_DIR}/datalab-fetch/scripts/national.py hot
```

| 5대 지표 | 외지인 방문자수·내국인 관광소비·방한 외래객수·외국인 관광소비·관광사업체 수 |
| 월별 추이 | 방한 외래객 · 국내 방문객 · 의료관광 소비 · 한류관광 소비 · 크루즈 입국자 |

| 관광수지 | 관광수지·수입·지출, 전체와 1인당 |
| 국민 국내여행 | 경험률·1인 평균 횟수/일수/지출액 (**설문조사**) |
| 불편신고 | 관광불편신고가 많은 시도 |
| 급등 동네 | 방문자가 급등한 행정동(내국인·외국인) |
| 급등 관광지 | 내비게이션 검색이 급등한 곳 |
| 인기 관광지 | 연령대별 검색 상위 |
| 시도 체류 | 시도별 평균 숙박일·체류시간 |

## 알아야 할 것

**표마다 모집단이 다르다.** 상위 국가 표는 열 나라만이라 더해도
전체가 되지 않고, 유입 구성 표는 대륙과 관문 두 갈래가 각각 100%가
된다(둘의 합이 2024년 16,369,629명으로 같은 것을 확인했다).

**국민 국내여행은 설문조사다.** 나머지 섹션이 이동통신·카드 기반
실측이나 집계인 것과 다르다. "경험률 97%"는 응답자 비율이다.
연 단위라 월별 추이와 나란히 두지 않았다.

**불편신고 건수만으로 "위험한 곳"이라고 읽지 마라.** 방문자가 많은
곳이 신고도 많다. 시도 단위까지만 있다.

### 기준 시점이 지표마다 다르다

한 화면에 있다고 같은 달이 아니다. 방한 외래객은 6월까지인데 국내
여행객은 7월까지다. 그래서 리포트는 **카드마다 기준 시점을 따로 적는다.**
"2026년 7월 기준"처럼 하나로 뭉뚱그리지 마라.

### 값의 단위와 증감의 단위가 다른 카드가 있다

관심도·긍정반응은 값이 `%`이고 증감이 `%p`다. 섞으면 "관심도가 59%
늘었다"처럼 틀린 문장이 된다. 사이트 코드에서 확인한 구분이다.

### 5대 지표는 출처가 서로 다르다

이동통신·신용카드·한국관광통계·지역행정 인허가에서 각각 온다. 같은
잣대로 잰 값이 아니므로 **서로 나누거나 빼지 마라.** 리포트에도 그
문장이 실린다.

### 방문자 수는 연인원이다

한 사람이 여러 지역을 가면 여러 번 센다. 인구와 비교하지 마라.

### 검색은 방문이 아니다

급등 관광지와 인기 관광지는 내비게이션 **검색 건수**다.

### 오지 않은 달을 0으로 읽지 마라

추이에서 요청한 달이 빠질 수 있다 — 아직 발표되지 않았기 때문이다.
리포트가 어느 달이 빠졌는지 그 표 밑에 적는다. 크루즈가 특히 늦다.

### 시도 체류는 18행이다

17개 시도가 아니다. `전남광주통합특별시`가 광주광역시·전라남도와 함께
오므로 **다 더하면 그 지역을 두 번 센다.** 체류시간은 사이트가 단위를
적어 두지 않아 확정하지 못했다 — 시도끼리 견주는 데만 써라.

## 하지 않는 것

- **점수를 매기지 않는다.** 전국은 비교 대상이 없다.
- **지역·국가로 쪼개지 않는다.** 그건 `region-market-scan`,
  `inbound-country-brief`의 일이다.
- **모르는 단위에 해석을 붙이지 않는다.**
